# Random-forest-and-decision-tree_task5
Random Forest and Decision Tree
This project demonstrates the use of decision tree-based machine learning models for classifying heart disease using the heart.csv dataset. It includes a comprehensive implementation of both a Decision Tree Classifier and a Random Forest Classifier using the Scikit-learn library. The script begins by training a basic Decision Tree model, visualizing the resulting tree structure, and analyzing the effects of varying tree depth to observe overfitting and underfitting. A Random Forest model is then trained and its performance compared with the Decision Tree. Key metrics such as accuracy, feature importances, and a detailed classification report are computed to evaluate the models. Cross-validation is performed to ensure robustness of the results. In addition, hyperparameter tuning is conducted using GridSearchCV to find the best configuration for the Random Forest model. The final section includes the visualization of the confusion matrix and the ROC curve along with AUC score to assess classifier quality. This project serves as a complete learning pipeline for decision tree models and ensemble methods, providing both visual and quantitative insights into their performance.
